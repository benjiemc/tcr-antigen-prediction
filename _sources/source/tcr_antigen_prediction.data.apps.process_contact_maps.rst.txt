tcr_antigen_prediction.data.apps.process_contact_maps
=====================================================
.. code-block:: text

   usage: python -m tcr_antigen_prediction.data.apps.process_contact_maps
          [-h] --mhc-pseudo-sequence-imgt-numbers
          MHC_PSEUDO_SEQUENCE_IMGT_NUMBERS --output OUTPUT
          [--mhc-types {MH1,MH2} [{MH1,MH2} ...]] [--smooth] [--pad]
          [--cdr1-alpha-length CDR1_ALPHA_LENGTH]
          [--cdr2-alpha-length CDR2_ALPHA_LENGTH]
          [--cdr3-alpha-length CDR3_ALPHA_LENGTH]
          [--cdr1-beta-length CDR1_BETA_LENGTH]
          [--cdr2-beta-length CDR2_BETA_LENGTH]
          [--cdr3-beta-length CDR3_BETA_LENGTH] [--peptide-length PEPTIDE_LENGTH]
          [--log-level {debug,info,warning,error}] [--log-file LOG_FILE]
          contacts
   
   Process contact information to use in downstream machine learning tasks.
   
   positional arguments:
     contacts              path to input contact data file
   
   options:
     -h, --help            show this help message and exit
     --mhc-pseudo-sequence-imgt-numbers MHC_PSEUDO_SEQUENCE_IMGT_NUMBERS
                           path to mhc pseudo sequence imgt numbers (JSON format)
     --output OUTPUT, -o OUTPUT
                           Path to output h5 file
   
   Data:
     --mhc-types {MH1,MH2} [{MH1,MH2} ...]
                           TCR:pMHC types to include (default: ['MH1', 'MH2'])
     --smooth              Use gaussian to smooth contact maps between TCRs and
                           peptides
     --pad                 Pad maps using the provided lengths
     --cdr1-alpha-length CDR1_ALPHA_LENGTH
                           Length to pad CDR 1a sequences to (Default: 8)
     --cdr2-alpha-length CDR2_ALPHA_LENGTH
                           Length to pad CDR 2a sequences to (Default: 8)
     --cdr3-alpha-length CDR3_ALPHA_LENGTH
                           Length to pad CDR 3a sequences to (Default: 24)
     --cdr1-beta-length CDR1_BETA_LENGTH
                           Length to pad CDR 1b sequences to (Default: 8)
     --cdr2-beta-length CDR2_BETA_LENGTH
                           Length to pad CDR 2b sequences to (Default: 8)
     --cdr3-beta-length CDR3_BETA_LENGTH
                           Length to pad CDR 3b sequences to (Default: 24)
     --peptide-length PEPTIDE_LENGTH
                           Length to pad peptide sequences to (Default: 12)
   
   Logging:
     Options for logging
   
     --log-level {debug,info,warning,error}
                           Level to log messages at (Default: 'warning')
     --log-file LOG_FILE   File to output logs (default is to write to stderr)
