tcr_antigen_prediction.models.apps.train_tcr_struct_map

usage: python -m tcr_antigen_prediction.models.apps.train_tcr_struct_map
       [-h] [--contact-maps CONTACT_MAPS] --output OUTPUT [--seed SEED]
       [--features-to-include {cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo,all} [{cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo,all} ...]]
       [--cdr1-alpha-length CDR1_ALPHA_LENGTH]
       [--cdr2-alpha-length CDR2_ALPHA_LENGTH]
       [--cdr3-alpha-length CDR3_ALPHA_LENGTH]
       [--cdr1-beta-length CDR1_BETA_LENGTH]
       [--cdr2-beta-length CDR2_BETA_LENGTH]
       [--cdr3-beta-length CDR3_BETA_LENGTH] [--peptide-length PEPTIDE_LENGTH]
       [--mhc-pseudo-length MHC_PSEUDO_LENGTH] [--batch-size BATCH_SIZE]
       [--num-epochs NUM_EPOCHS] [--learning-rate LEARNING_RATE]
       [--drop-out-rate DROP_OUT_RATE] [--learn-contact-maps]
       [--checkpoint-interval CHECKPOINT_INTERVAL]
       [--eval-interval EVAL_INTERVAL] [--eval-batch-size EVAL_BATCH_SIZE]
       [--log-level {debug,info,warning,error}] [--log-file LOG_FILE]
       training_data

Train TCRContactMapPredictor model.

options:
  -h, --help            show this help message and exit
  --seed SEED           Seed for random processes (Default: None)

Inputs:
  training_data         path to the training data (HDF5 file)
  --contact-maps CONTACT_MAPS
                        path to contact maps for each CDR-peptide/mhc
                        interaction (HDF5 file)

Outputs:
  --output OUTPUT, -o OUTPUT
                        path to output directory for models

Data Parameters:
  --features-to-include {cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo,all} [{cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo,all} ...]
                        features to include in training (Default: all). This
                        is useful for understanding the impact of different
                        features on model perfomance.
  --cdr1-alpha-length CDR1_ALPHA_LENGTH
                        maximum CDR1-alpha length (Default: 8)
  --cdr2-alpha-length CDR2_ALPHA_LENGTH
                        maximum CDR2-alpha length (Default: 8)
  --cdr3-alpha-length CDR3_ALPHA_LENGTH
                        maximum CDR3-alpha length (Default: 24)
  --cdr1-beta-length CDR1_BETA_LENGTH
                        maximum CDR1-beta length (Default: 8)
  --cdr2-beta-length CDR2_BETA_LENGTH
                        maximum CDR2-beta length (Default: 8)
  --cdr3-beta-length CDR3_BETA_LENGTH
                        maximum CDR3-beta length (Default: 24)
  --peptide-length PEPTIDE_LENGTH
                        maximum peptide length (Default: 12)
  --mhc-pseudo-length MHC_PSEUDO_LENGTH
                        length of MHC pseudo sequences (Default: 26)

Training Parameters:
  --batch-size BATCH_SIZE
                        training batch size (Default: 32)
  --num-epochs NUM_EPOCHS
                        number of epochs (Default: 25)
  --learning-rate LEARNING_RATE
                        optimizer learning rate (Default: 1e-3)
  --drop-out-rate DROP_OUT_RATE
                        Drop-out rate for training (Default: 0.2)
  --learn-contact-maps  Unfreeze contact map values during training
  --checkpoint-interval CHECKPOINT_INTERVAL
                        interval to save the model during training (Default:
                        1000)

Validation Parameters:
  --eval-interval EVAL_INTERVAL
                        Interval to evaluate model performance (Default: 500)
  --eval-batch-size EVAL_BATCH_SIZE
                        batch size for evaluating the model (Default: 1000)

Logging:
  Options for logging

  --log-level {debug,info,warning,error}
                        Level to log messages at (Default: 'warning')
  --log-file LOG_FILE   File to output logs (default is to write to stderr)
